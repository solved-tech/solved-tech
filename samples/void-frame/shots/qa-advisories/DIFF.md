# Stamp separator — before and after

The short code and the full name used to read as one run, `001001 / brutalism`. A visually hidden space between them makes the stamp text `001 001 / brutalism`. The space is taken off the line so the glyphs stay where they were.

Each pair is the same viewport, device scale 1, Oswald 400 and 700 loaded, animations held at 0, and nothing focused. Differing pixels are 0.
