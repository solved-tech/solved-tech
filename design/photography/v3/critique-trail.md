## Round 3 — Contact Sheet revision (this deliverable)

**Changes forced by Design Researcher:**
1. Real sequences — three strips × five near-identical burst frames (crop/tilt/exposure from one source each). Story = choosing.
2. Physical film — Kodak edge print, arrows, sprocket holes, black film border, strip misregistration, frames cut at sheet edge.
3. Wax grease pencil — double-stroke wobbly circles, uneven star, crop-mark L, reject X. No clean UI rects/perfect circles. Loupe hover state shown magnifying keep 07B1.
4. Fogged 07E–H removed.
5. Shorthand captions — frame no., f-stop, keep / soft / eyes closed. “Hold these frames” retained.
6. Mobile — one strip scrolls horizontally (pull through loupe), not stacked cards.

### Honest residual risks (self-score)
- Burst frames are derived variants, not a true motor-drive take — a sharp eye may notice synthetic continuity. Acceptable for sample if sequence reads first.
- Grease is SVG double-stroke, not photographed wax — better than UI circles; still not analog scan.
- Loupe is a static “hover shown” in the mockup, not interactive JS (design-only deliverable).

**Self-score estimate: 37–39 / 50.** Concept and objecthood clear; craft of marks and film evidence carry the lift from 31; remaining points held back by derived bursts and drawn (not scanned) grease.

## Round 4 — Contact Sheet (Design Researcher 34/50 → revise)

**Problem called:** five frames per strip visibly the same photo.

**Real sequences?** Searched Unsplash for same-photographer / same-shoot bursts. **Not found** — Unsplash publishes selects, not contact bursts; photographer pages returned 401 without auth. Licence-verified sources remain the existing Unsplash stills.

**Fix applied (derived, strong):**
- Per frame: 3–8% crop + position drift, rotation, ±0.3 stop exposure
- One motion-blur frame per strip; one OOF “missed” frame carries the reject mark
- Strip angles/spacing increased; strip C runs farther off the sheet
- Grease pressure varies: strip A heavy/large, strip C light/small
- Handwritten note: “print 8×10”
- Enquire + notes bumped up a size on desktop
- Keeps now 07A2 · 07B2 · 07C3
